# Project: AI-Powered Concentrix US BPO Non-Voice Interview Preparation Website

Act as a senior full-stack software engineer, UI/UX designer and AI application architect. Build a complete, responsive, AI-powered web application for preparing candidates for **Concentrix US BPO – Non-Voice (Email and Chat Support) recruitment assessments**.

The application should provide a realistic practice environment, generate unique questions for every attempt, evaluate responses and help candidates improve their performance.

## 1. Main Objective

Build an interactive interview preparation platform that covers:

1. English grammar and vocabulary
2. Reading comprehension
3. Typing speed and accuracy
4. Email writing
5. Customer chat simulations
6. Aptitude and logical reasoning
7. Customer service scenarios
8. HR interview preparation
9. Full-length mock assessments

The website must not require its own database. Use AI-generated questions, publicly available reference information and browser localStorage for optional local progress tracking.

Clearly distinguish practice tests generated by AI from verified official Concentrix assessment information. Never claim that generated questions are actual company exam questions.

## 2. Technology Stack

Use the following technologies:

* Frontend: Next.js (App Router) and React
* Language: TypeScript
* Styling: Tailwind CSS
* UI components: shadcn/ui
* Icons: Lucide React
* AI: OpenAI API
* Validation: Zod
* Charts: Recharts
* Storage: Browser localStorage
* Deployment: Vercel

Use the current stable, mutually compatible package versions when implementing the project.

Keep the architecture modular, maintainable and suitable for future expansion.

## 3. Website Design

Create a professional, modern, clean and responsive dashboard.

Design requirements:

* Professional educational SaaS-style interface.
* Desktop, tablet and mobile compatibility.
* Light and dark modes.
* Sidebar navigation on desktop and mobile-friendly navigation.
* Dashboard with cards, progress indicators and charts.
* Clear instructions before starting each assessment.
* Accessible forms, keyboard navigation and readable typography.
* Consistent spacing, colors and reusable components.

Website name: **BPO Prep AI**

Subtitle: AI-powered Concentrix US BPO Non-Voice Interview Preparation.

Do not use the official Concentrix logo or imply that this is an official Concentrix website.

Create a dashboard with the following cards:

* English Assessment

## 5. AI Question Generation Engine

This is the most important feature.

Use the OpenAI API to generate fresh questions dynamically according to the selected test category, difficulty, number of questions and time limit.

Every test should have a unique set of questions wherever possible.

The question generator should support:

* Easy, intermediate and advanced difficulty
* Multiple-choice questions
* Fill-in-the-blank questions
* Sentence correction
* Reading comprehension
* Business email writing
* Customer chat conversations
* Numerical reasoning
* Logical reasoning
* Customer service scenarios

For multiple-choice questions, return:

* Unique question ID
* Question
* Four answer options
* Correct answer
* Explanation
* Difficulty
* Topic
* Estimated time

For written questions, return:

* Question or customer scenario
* Instructions
* Expected response format
* Evaluation rubric
* Maximum score

Use structured JSON output and validate every generated response with Zod.

Do not show correct answers before the candidate submits their responses.

Avoid duplicate questions within a single test. Use different scenarios, wording and difficulty combinations across attempts. Where practical, use a random seed or varied generation instructions, but do not rely on a random seed alone to guarantee uniqueness.

Generate questions on demand rather than storing a large question bank.

If AI generation fails, display a clear error message and allow the candidate to retry. Include a small, original, predefined fallback question set in the application for basic practice.

## 6. Test Modules

### Module A: English Grammar and Vocabulary

Include:

* Tenses
* Articles
* Prepositions
* Subject-verb agreement
* Sentence correction
* Vocabulary
* Synonyms and antonyms
* Professional English

Allow candidates to choose 10, 20 or 30 questions.

At the end, show:

* Correct and incorrect answers
* Total score
* Accuracy
* Explanation for each question
* Topics requiring improvement

### Module B: Reading Comprehension

Generate original business-related passages and questions.

Include:

* Main idea
* Specific details
* Inference
* Vocabulary in context
* Understanding instructions

Display one passage with its associated questions. Support a timed mode and an untimed practice mode.

### Module C: Typing Test

Create a working typing test with:

* 1-minute, 2-minute, 3-minute and 5-minute options
* Randomly selected practice passages
* Live elapsed time
* Words per minute (WPM)
* Correct characters
* Incorrect characters
* Accuracy percentage
* Final results

Use the following calculations:

WPM = Correct characters / 5 / Elapsed time in minutes

Accuracy = Correct characters / Total typed characters × 100

Clearly distinguish gross WPM from net WPM if both are displayed. Ensure the timer cannot become negative and the test cannot be submitted twice.

Typing tests must work entirely in the browser without an AI request.

### Module D: Email Writing Assessment

Generate realistic US customer support scenarios, such as:

* Delayed orders
* Refund requests
* Account access issues
* Billing disputes
* Incorrect products
* Service complaints

Ask the candidate to write a professional email.

Evaluate the response using the AI API against a transparent 100-point rubric:

* Grammar and spelling: 25 points
* Professional tone: 20 points
* Clarity and readability: 20 points
* Completeness: 20 points
* Customer empathy: 15 points

Display:

* Overall score
* Category-wise scores
* Strengths
* Mistakes
* Suggested corrections
* An improved example response

Do not reward unnecessary verbosity. Evaluate whether the response answers the customer's actual question.

### Module E: Chat Support Simulation

Build an interactive simulated customer chat.

The AI plays the role of a US customer. The candidate plays the customer support representative.

Include scenarios involving:

* Frustrated customers
* Refund requests
* Order tracking
* Account problems
* Billing errors
* Product complaints

The AI should maintain consistent customer details throughout the conversation. The candidate should be able to send multiple messages and end the simulation.

Evaluate:

* Communication
* Empathy
* Accuracy
* Problem-solving
* Professionalism
* Resolution

Provide detailed feedback at the end of the simulation.

Do not let the simulated customer disclose the hidden evaluation rubric or expected answers during the test.

### Module F: Aptitude and Logical Reasoning

Generate questions on:

* Percentages
* Ratios
* Averages
* Number series
* Basic arithmetic
* Logical sequences
* Simple analytical reasoning

Provide a calculator-free practice mode and an optional untimed learning mode.

Show explanations after submission.

### Module G: Customer Service Scenarios

Present realistic situations that a non-voice customer support representative might encounter.

Examples:

* A customer sends an angry email about a delayed refund.
* A customer provides incomplete information.
* A customer reports an account access issue.
* A customer asks for an update that is not yet available.

Allow multiple-choice and written-response formats.

Evaluate the candidate's decisions using clearly defined customer service principles. Do not invent Concentrix internal policies.

### Module H: HR Interview Practice

Include practice questions such as:

* Tell me about yourself.
* Why do you want to work in a non-voice process?
* Why Concentrix?
* How would you handle an angry customer?
* Are you comfortable working night shifts?
* How do you manage repetitive tasks?
* What are your strengths?
* Why should we hire you?

Allow candidates to type their answers and optionally receive AI feedback on clarity, relevance, grammar and professionalism.

### Module I: Full Mock Assessment

Create a configurable full mock assessment combining the preceding modules.

Default practice configuration:

| Section            | Questions/tasks | Suggested duration |
| ------------------ | --------------: | -----------------: |
| English            |              15 |             15 min |
| Reading            |               5 |             10 min |
| Aptitude           |              10 |             15 min |
| Typing             |       1 passage |              3 min |
| Email writing      |               1 |             15 min |
| Customer scenarios |               5 |             10 min |

These are practice settings, not the official Concentrix examination pattern.

Allow candidates to modify the number of questions and the duration before starting.

At the end, show a consolidated report with scores for every section, total completion time and recommendations.

## 7. AI Evaluation and Feedback

Create a reusable AI evaluation service.

For each submitted test:

1. Evaluate the answers against the question's correct answer or rubric.
2. Calculate scores using the defined rules.
3. Explain errors in simple English.
4. Identify strengths and weaknesses.
5. Suggest targeted practice exercises.
6. Return structured JSON.
7. Validate the result before displaying it.

For objective questions, calculate correctness deterministically in the application instead of asking AI to decide whether a selected option is correct.

Use AI primarily for open-ended responses, email writing, chat simulations and personalized explanations.

Keep the evaluation criteria consistent between attempts.

## 8. No Database Architecture

Do not create PostgreSQL, MySQL, MongoDB, Supabase or Firebase dependencies.

Use:

* OpenAI API for dynamic question generation and written-response evaluation.
* localStorage for user preferences, practice history and saved progress.
* React state for active tests.
* In-memory state for temporary AI chat sessions.

Provide an option to clear all locally saved data.

Do not store API keys, private prompts or sensitive information in localStorage.

Do not claim that progress is synchronized across devices. Explain that browser-based progress can be lost if browser data is cleared.

## 9. OpenAI API Integration

Implement server-side API routes for:

* Generating questions
* Evaluating written responses
* Running customer chat simulations
* Generating personalized study plans

Use the official OpenAI SDK and the Responses API where appropriate.

Requirements:

* Store the API key in an environment variable named OPENAI_API_KEY.
* Never expose the API key in client-side code.
* Use server-side validation.
* Add request size limits and basic rate limiting.
* Handle API timeouts and errors.
* Avoid sending unnecessary personal information to the AI.
* Keep prompts in separate, maintainable files.
* Make the model configurable through an environment variable.
* Never assume a particular model is available without checking configuration.

Provide an .env.example file with placeholder values only.

Keep factual company information separate from AI-generated practice questions.

## 13. Security and Reliability

* Protect all AI API calls on the server.
* Validate all client inputs and AI responses.
* Apply rate limits to prevent excessive API usage.
* Avoid exposing system prompts.
* Prevent duplicate submissions.
* Handle interrupted sessions gracefully.
* Never mark an unanswered question as correct.
* Avoid treating AI-generated answers as verified company policy.
